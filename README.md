# Telegram-бот "Академический ассистент" (LangGraph)

Программа представляет собой Telegram-бота с ИИ-агентом на базе LangGraph, который собирает, анализирует и сортирует учебные материалы по четырем дисциплинам: Численные методы, Компьютерные сети, Программирование на Python и Физика. Разработано в рамках интенсива "Школы 21".

## Возможности бота

- **Маршрутизация на LangGraph**: Бот использует граф-архитектуру со сменными состояниями (StateGraph) для обработки диалогов и вызова инструментов.
- **Интеграция GigaChat API**: Модель классифицирует тексты по заданным предметам и извлекает метаданные с помощью структурированного вывода (with_structured_output).
- **Сбор данных (Парсинг)**: Библиотека BeautifulSoup4 извлекает полезный текст по веб-ссылкам, очищая его от скриптов и стилей.
- **Работа с локальной БД (JSON)**: Бот содержит инструменты для валидации карточек через Pydantic, сохранения их в файл `requests.json` и фильтрации записей по датам и предметам.

## Стек технологий

- Python 3.13
- LangGraph, LangChain, GigaChat API
- BeautifulSoup4, Pydantic, Requests
- pyTelegramBotAPI (telebot)
- Python-dotenv

## Развертывание проекта

Конфигурация проекта вынесена в переменные окружения. Перед запуском необходимо скрыть конфиденциальные данные.

1. Склонируйте этот репозиторий:
```bash
git clone https://github.com
cd langgraph-academic-assistant
```

2. Установите необходимые пакеты:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` в корне проекта и добавьте туда токены авторизации:
```text
GIGACHAT_API_KEY=ваш_ключ_от_gigachat
TELEGRAM_BOT_TOKEN=ваш_токен_боты_из_botfather
```

4. Запустите скрипт:
```bash
python langgraph-academic-assistant.py
```
